# score.txt -- the scoreboard's questions. "question => pattern" is scored: the reply must match the pattern (a regular
# expression, case ignored). A line without "=>" is said but not scored, to set up what follows. "# heading" starts a
# group, and each group starts a fresh Nuage. Written to be fair: an expectation is the right answer, not what Nuage
# happens to say, so a failure here is a true failure. Add questions freely; the totals are only worth what the set is.
